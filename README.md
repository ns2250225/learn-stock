# 像素证券城 · Pixel Stock City

> 像素风股票模拟经营网页游戏 —— 在一个持续运行、会发生新闻事件与市场周期的虚拟市场中，体验从开户、研究、下单、持仓管理到复盘的完整投资流程。

**⚠️ 免责声明：所有资金、公司、价格、新闻与收益均为虚构模拟数据。** 本游戏不连接任何真实券商，不处理充值提现，不下达真实委托，游戏结果不构成任何投资建议。

## ✨ 游戏简介

玩家从「实习投资者」开始，在像素证券城中逐步建立自己的投资体系：

- 📰 **阅读新闻** —— 宏观事件、行业动态、公司公告与财报，新闻会影响行情，但不会被机械地映射为固定涨跌；
- 🔍 **研究公司** —— K 线 / 分时、虚拟盘口、财报（实际 vs 预期）、估值指标、公司档案与行情归因；
- 📝 **制订计划** —— 交易前填写理由、目标、风险与退出条件，培养交易纪律；
- 💹 **提交订单** —— 市价 / 限价 / 止损 / 止损限价，体验部分成交、撤单与拒单；
- 🛡️ **管理仓位** —— 费用、T+1 交收、分红拆股、停牌退市，进阶模式还有保证金与卖空；
- 📊 **复盘成长** —— 收盘总结、交易复盘、行为偏差提示、任务 / 成就 / 错题本。

## 🎮 游戏模式

| 模式 | 说明 |
| --- | --- |
| 新手教学 | 任务驱动、事件节奏较慢，关键步骤提供解释，初始资金固定 |
| 自由模拟 | 市场长期运行，可自定义初始资金，支持暂停、单步推进与时间倍率调整 |
| 情景挑战 | 从指定资金、持仓与市场环境出发，在限定交易日内达成目标，结束后多维度评估 |

开局时还可以选择 **难度**（影响事件频率、波动率、可见信息等）与 **世界种子**（同一 seed 可复现同一市场）。

## 🚀 快速开始

环境要求：Node.js ≥ 18（推荐 20+）。

```bash
git clone https://github.com/ns2250225/learn-stock.git
cd learn-stock
npm install

npm run dev      # 开发模式
npm run build    # 类型检查 + 生产构建（输出 dist/，纯静态网页，可直接部署）
npm run preview  # 预览构建结果
```

构建产物为纯静态网页，可部署到任意静态托管服务。存档保存在浏览器本地（IndexedDB），支持自动存档、3 个手动存档槽以及存档导出 / 导入 JSON。

## 🕹️ 操作与可访问性

- 响应式布局，桌面与移动端均可游玩；
- 键盘快捷键：搜索股票、切换页面、聚焦下单数量、打开订单列表等，可在设置中关闭或自定义；
- 可访问性设置：放大字号、降低闪烁、关闭动效、高对比模式。

## 🧰 技术栈

- **框架**：Vue 3 + TypeScript + Pinia
- **构建**：Vite
- **渲染**：像素场景与图表均为原生 Canvas 绘制，无第三方图表库
- **持久化**：IndexedDB（存档槽、自动 / 手动存档、导入导出），LocalStorage（轻量设置）

### 模拟时间步顺序

`Engine.step()` 每个模拟分钟按固定顺序执行：时钟与阶段 → 撤单（先撤后撮）→ 日历事件 / 连锁与剧本事件 → 随机事件 → 市场/行业因子 → 个股参考价 → 虚拟盘口 → 止损触发 → 价格优先、时间优先撮合 → 费用、冻结/解冻、持仓 → 不可变流水与行情快照 → 风险、提醒、保证金 → 自动存档标记。

### 价格模型

个股潜在 log 价格 = 基本面公允价值 + β·市场因子 + 行业敏感度·行业因子 + 偏离项。偏离项包含事件冲击（按可信度、预期差、已定价程度和市场解读分歧计算，分步释放）、情绪/趋势项、估值回归与随机扰动。基本面随营收增速、利润率、宏观估值乘数（利率、国债收益率、大宗商品、消费者信心、风险偏好）逐日变化；市场因子在不同市场状态（上升/下行/横盘/高波动/泡沫/危机）间切换并向宏观隐含水平回归，避免价格长期归零或指数级增长。每个交易日累计各因素贡献，供「行情归因」展示（以区间呈现，并声明不是唯一真实原因）。

### 可复现性

每个存档有 `worldSeed`，市场、个股、盘口、事件、财报、公司行动、宏观、观点各使用独立随机流（`rng.ts`，sfc32）。玩家下单与撤单不消耗任何随机流，只通过有限盘口深度影响成交；随机数从不在渲染中抽样。

## ⚠️ 关键简化说明

- 盘口为按流动性档位生成的虚拟深度，不是真实参与者订单；被动挂单按分钟价格区间与成交量近似估算成交。
- 「A 股风格」「美股风格」规则包是公开规则的教学近似，费率与制度会调整，正式使用前须以官方资料核对。
- 历史行情为开局时用同一模型预生成的虚构数据，不对应任何真实市场。
